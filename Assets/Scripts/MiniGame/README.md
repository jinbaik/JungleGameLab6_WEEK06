# Dev_MiniGame

Unity 6000.3.22f1 / URP / Input System / uGUI / Cinemachine 환경의 개발 씬이다.
Unity Pipeline 패키지에 연결된 `unity command` CLI로 씬을 구성했다.

## 플레이

- `Assets/Scenes/Dev_MiniGame.unity`를 실행하고 Game 창을 선택한다.
- 첫 미니게임은 15초 후 해킹 또는 단어 입력 중 무작위로 시작한다.
- 실행 중에는 제한 시간과 추가 이벤트가 없다. 클리어 후 다음 15초를 세되, 피버 중에는 대기 시간을 세지 않고 피버 종료 후부터 15초를 센다.
- 해킹: Escape를 제외한 키를 반복해서 누른다. 새 눌림마다 8% 상승하고 초당 6% 감소한다. 100%면 성공한다. 키를 계속 누르고 있는 것만으로는 해킹 진행도가 증가하지 않는다.
- 단어 입력: 표시된 5~6글자 영문 단어를 입력한다. 목표 길이에 도달하면 자동 제출하며 Backspace로 수정할 수 있다. 오답은 목표만 교체하고 정답 수를 유지한다. 6개 정답이면 성공한다. Shift와 Caps Lock은 필요 없다.
- 클리어마다 피버 Slider가 50% 오른다. 두 번 클리어하면 기본 5초간 직접·광역 피해가 2배가 된다. 같은 Slider가 피버 중에는 발동 시 확정한 지속시간 대비 남은 시간 비율을 표시하며 100%에서 0%로 줄어든다.
- 피버 지속시간 강화는 레벨당 2초, 피해 배율 강화는 레벨당 0.3배 증가한다. 두 강화는 각각 최대 3레벨이며 구매 가격은 60 / 120 / 300이다. 효과는 피버 발동 시 세션에서 조회하며 피버 중 구매한 강화는 다음 피버부터 적용한다. 최종 직접·광역 피해는 배율 적용 후 한 번 올림한다.
- Escape는 기존 카메라 전환에 사용하며 미니게임 입력에서 제외한다.

## 씬 구성

- `Monitor/Screen/MiniGameScreen`: 모니터 앞면의 World Space Canvas. 해킹 진행도와 명령 로그, 단어 목표와 현재 입력, 피버 충전도를 표시한다.
- `MiniGameSystem`: 이벤트 일정과 피버 상태의 소유자 및 UI 표시 컴포넌트.
- `MiniGameSystem/MiniGameHUD`: 화면 우측 상단의 HUD. 피버 충전도와 활성 상태의 남은 초·시간 막대·데미지 배율을 표시한다.
- `KeyboardInputController`: 기존 Windows 단축키 캡처 및 키 모델 입력 경로를 사용한다. 새 눌림 이벤트를 미니게임에 전달하고 연결된 미니게임의 데미지 배율을 적용한다. 다른 씬에서 미니게임 참조가 없으면 기존 데미지 1을 유지한다.
- 기존 두 Cinemachine 카메라는 이 씬에서 모니터와 키보드가 모두 보이도록 배치했다.

`MiniGameController` Inspector에서 이벤트 간격, 해킹 증가·감소량, 정답 개수와 강화 구매 세션을 연결할 수 있다. 세션이 없는 개발 씬은 기본 피버 5초 / 2배를 사용한다. 피버 강화 에셋에서 기본값과 레벨당 증가량을 조정하며 UpgradeId에 해당하는 효과 설정만 Inspector에 표시된다.

`Tools > Mini Game > Configure Dev_MiniGame`은 초기 구성을 재현하는 Editor 도구다. 이미 구성된 씬에서는 중복 생성하지 않는다. UI 참조는 모두 씬에 저장되어 있으므로 실행 전 추가 설정은 필요 없다.

## 구현 경계

미니게임과 난타는 기존 키보드 입력을 함께 사용한다. 미니게임 중에도 기존 키캡 데미지와 파괴 동작은 유지된다. 해킹 로그는 게임 연출용 문자열이며 실제 시스템 명령을 실행하지 않는다. 일시정지 시에는 이벤트, 진행도 감소, 피버 시간이 함께 멈춘다.
